`feeder` draws a distribution feeder in one call: a straight run with an
evenly-spaced tap per station, an optional transformer +
[`load`](/symbols/loads/load/) "drop" under each, per-segment current
labels, and a dashed continuation. It's a composition helper — it loops
`wire`, `transformer`, `load`, and `note` over a data list, so you
*describe* the feeder instead of placing every element by hand.

<Snippet name="feeder-example" />

```typst
feeder("f", (0, 0),
  (
    (label: [N1 \ 10,4 kV], load: [10 A \ 230 V]),
    (label: [N2 \ 10,4 kV], load: [10 A \ 230 V]),
    (label: [N3 \ 10,4 kV], load: [10 A \ 230 V]),
  ),
  currents: ([56 A], [47 A], [38 A], [28 A]))
```

## The station list

`stations` is a list of dictionaries — one per tap, left to right:

- `label` (content | none) — caption beside the tap (station id, voltage,
  …), placed on the side opposite the drop.
- `load` (content | none) — caption under the load arrow (the LV rating).
  When present, a transformer + load drop is drawn; when omitted the
  station is a **bare labelled tap**.
- `tx` (bool) — per-station override of the feeder-wide `tx` flag; set
  `false` to hang the load straight off the tap (no transformer).
- `stroke` / `fill` — per-station load-arrow styling (thin / thick /
  coloured), overriding the feeder-wide `load-stroke` / `load-fill`.
- `tx-stroke` / `tx-fill` — per-station transformer styling, overriding the
  feeder-wide `tx-stroke` / `tx-fill`.
- `draw` (function) — a custom drop drawer for this station (a motor,
  capacitor, sub-feeder, …), overriding the feeder-wide `drop-draw`. See
  [Custom drops](#custom-drops).

`currents` is a separate list of segment labels. A feeder of N stations has
**N + 1** segments — the lead-in, each inter-station gap, and the tail — so
pass up to N + 1 entries; `none` skips one (handy when a segment is
labelled elsewhere, e.g. a step-down).

## Parameters

| Name | Default | Description |
| ---- | ------- | ----------- |
| `start` | — | Where the run begins (any CeTZ coordinate, e.g. a bus anchor). |
| `stations` | — | Per-tap data list (see above). |
| `currents` | `()` | Segment labels, up to `N + 1`; `none` skips one. |
| `lead` | `1.7` | Distance from `start` to the first station. |
| `spacing` | `2.5` | Distance between consecutive stations. |
| `tail` | `auto` | Last station → line end (`auto` = `lead`). |
| `extend` | `0.6` | Dashed continuation past the end (`0` = none). |
| `angle` | `0deg` | Angle of attack — the direction the run travels. |
| `drop-angle` | `auto` | Direction the drops travel (`auto` = perpendicular to the run). |
| `drop-draw` | `auto` | What hangs at each tap (`auto` = transformer + load). See [Custom drops](#custom-drops). |
| `line-stroke` | `auto` | Stroke of the run (`auto` = the active `cetz-power.wire.stroke`). |
| `extend-stroke` | `auto` | Stroke of the dashed tail (`auto` = the run's stroke + dash). |
| `extend-stroke` | `(dash: "dashed")` | Stroke of the dashed continuation. |
| `drop` | `0.95` | Length of the transformer + load drop. |
| `up` | `false` | Hang drops above the run instead of below. |
| `dot` | `0.06` | Tap-dot radius (`0` = no dot). |
| `label-gap` | `0.5` | Tap → station-caption distance. |
| `load-gap` | `0.35` | Gap from the load arrow tip to its caption (tracks `drop`). |
| `tx` | `true` | Draw a transformer in each drop (`false` = load only). |
| `tx-radius` / `tx-distance` | `0.2` / `0.22` | Drop transformer geometry. |
| `tx-stroke` / `tx-fill` | `0.8pt + black` / `none` | Default transformer styling (per-station `tx-stroke` / `tx-fill` override). |
| `load-size` / `load-lead` | `0.26` / `0.12` | Drop load-arrow geometry. |
| `load-stroke` / `load-fill` | `0.8pt + black` / `black` | Default load-arrow styling (per-station `stroke` / `fill` override). |

The i-th station's transformer and load get `<name>-t<i>` / `<name>-l<i>`
group names, so you can still anchor to them afterwards.

## Custom drops

The transformer + load drop is just the default. Pass a `drop-draw` closure
(feeder-wide) or a per-station `draw` to hang **anything** off a tap — a
motor, a capacitor bank, a breaker, even another feeder.

The closure receives one `info` dictionary:

| Field | Meaning |
| ----- | ------- |
| `info.name` | A unique base name for this station's elements. |
| `info.at` | The tap coordinate (where the drop meets the run). |
| `info.foot` | The drop's end point (`at` + `drop` along the drop direction). |
| `info.angle` | The drop direction, as an angle (so you can orient symbols). |
| `info.drop` | The drop length. |
| `info.st` | The station dict itself (read your own custom keys). |

The feeder still owns the run line, the tap dot, the station `label`, and the
current labels — the closure only fills the drop.

:::caution
You're placing real symbols, so respect each one's API: connect one-node
symbols (`machine`, `capacitor`, `pv-panel`) with your own wire and orient
them with `angle:`, give two-node symbols (`transformer`) both endpoints
(`info.at`, `info.foot`), and size a drop's contents to fit `info.drop` —
a body wider than the drop will overlap the run.
:::
