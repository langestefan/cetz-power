The full modified CIGRE low-voltage benchmark on one canvas: an external
grid feeds an MV bus (switch **S2**, 11 kV) and an **11/0.4 kV, 250 kVA**
transformer onto the 400 V **LV bus**, which fans out into three radial
feeders — **residential** (R1–R13), **industrial** (a single 100 m run to
I1), and **commercial** (C1–C14). Every segment carries its length, and
loads hang off the nodes as direction arrows.

## How it's built

It's a radial tree, so the whole diagram is one **LV bus** with three main
lines branching off — drawn by a couple of small closures rather than placed
by hand:

- `nodes(start, n, step, dir)` returns `n` coordinates a `step` apart from
  `start` along a unit vector (`down` / `left` / `right`); `chain(...)` walks
  them, drawing a [`wire`](/symbols/grid/wire/) per hop (each labelled with
  its length), a dot, and the node label. So a whole feeder line is two
  calls:

  ```typst
  let C = nodes((cx, by), 6, cs, down)                     // C1 … C6 coords
  chain((cx, by), C, [30m], range(1, 7).map(i => [C#i]),  // draw + label them
    ("west", "east", "east", "west", "west", "east"))
  ```

- The horizontal sub-feeders (R9–R11, C7–C8, C11–C12) use the same
  `nodes`/`chain` pair; `drop(...)` taps a node circle a branch below its
  parent and hangs a [`load`](/symbols/loads/load/) off it (the
  C9/C10/C13/C14/R12 pattern). `dl` rotates the length label to run along
  vertical segments.
- The three rooftop **PV panels** (R8, R9, C6) are the one hand-placed bit
  — a [`pv-panel`](/symbols/generation/pv-panel/) at the node, rotated for
  the C6 one.
- The top chain is built explicitly — [`external-grid`](/symbols/grid/external-grid/),
  a [`switch`](/symbols/protection/switch/) (S2) above a
  [`bus`](/symbols/grid/bus/) (the MV bus), and a
  [`transformer`](/symbols/grid/transformer/) down to the LV `bus`.

Because the feeders are `nodes` + `chain` + a label list, re-spacing one or
adding a node is a one-line change.
