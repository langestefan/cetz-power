The IEC cell symbol: a long thin line (positive plate) over a short
one (negative plate), with a lead at each end. Default orientation
puts `in` (negative) at the bottom and `out` (positive) at the top.

## Single-pole form

Pass `lead-out: 0` to drop the upper lead, e.g. when the battery
terminates against a busbar. Like the capacitor, `out`/`north` then
land on the top plate so chained wiring keeps working.

## Parameters

| Name          | Default         | Description                                                        |
| ------------- | --------------- | ------------------------------------------------------------------ |
| `cells`       | `1`             | Number of long/short plate pairs.                                  |
| `long-width`  | `0.5`           | Width of the long (positive) plate.                                |
| `short-width` | `0.22`          | Width of the short (negative) plate.                               |
| `gap`         | `0.12`          | Vertical distance between the plates of one cell.                  |
| `cell-gap`    | `0.18`          | Vertical distance between consecutive cells.                       |
| `lead-in`     | `0.3`           | Lead below the stack.                                              |
| `lead-out`    | `0.3`           | Lead above the stack. `0` drops it (single-pole form).             |
| `lead`        | –               | Shorthand: sets both leads at once (an explicit one still wins).   |
| `stroke`      | `0.8pt + black` | Stroke for leads and plates.                                       |
| `label`       | `none`          | Standard label dict (default `anchor: "north"`, `distance: 0.15`). |
| `angle`       | `0deg`          | Rotation around the connection point.                              |

## Anchors

| Anchor                     | Position                                              |
| -------------------------- | ----------------------------------------------------- |
| `in` / `default` / `south` | The negative terminal — the connection point.         |
| `out` / `north`            | The positive terminal (top plate when `lead-out: 0`). |
| `east`, `west`             | Long-plate ends at mid-height.                        |
| `center`                   | Centre of the cell stack.                             |
