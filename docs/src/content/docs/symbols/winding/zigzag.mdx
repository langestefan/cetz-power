The zigzag primitive draws three arms from a common neutral, each
with a single perpendicular kink. The kink direction is consistent
across all three arms so the shape reads as having a clear rotational
handedness — the conventional "broken Y" used for interconnected-star
secondaries (Dz, Yz vector groups).

## Parameters

| Name             | Default           | Description                                                                                            |
| ---------------- | ----------------- | ------------------------------------------------------------------------------------------------------ |
| `size`           | `0.6`             | Radial reach from centre to each terminal.                                                             |
| `terminals`      | `("U", "V", "W")` | Three label values in (U, V, W) order.                                                                 |
| `body`           | `true`            | Set to `false` to suppress the kinked arms and terminal labels — useful for skeleton-mode composition. |
| `stroke`         | `0.8pt + black`   | Stroke for the three arms.                                                                             |
| `zigzag-kink`    | `0.5`             | Fraction along each arm where the kink sits (0 = centre, 1 = terminal). Family-dict only.              |
| `zigzag-offset`  | `0.18`            | Lateral jog at the kink, as a fraction of `size`. Family-dict only.                                    |
| `label-size`     | `8pt`             | Terminal-label font size.                                                                              |
| `label-distance` | `0.18`            | Radial offset of terminal labels.                                                                      |
| `angle`          | `0deg`            | Rotation around the neutral. Use `-clock * 30deg` for IEC vector groups.                               |
| `label`          | `none`            | Outer caption.                                                                                         |

## Anchors

Same set as the [wye winding](/symbols/winding/wye/#anchors): `u`,
`v`, `w` at the terminals; `mid-u`, `mid-v`, `mid-w` at the kink
point on each arm; `neutral` / `center` / `default` at the common
centre; `north`, `south`, `east`, `west` on the bounding circle;
`in` / `out` as aliases for the placement coordinate.
