Three-winding transformer drawn as the conventional **trefoil** — three
mutually-overlapping circles. The default orientation is _vertex-left_:
the high-voltage (primary) winding sits on the left, and the two
secondaries are stacked on the right — upper (`lv`) and lower (`tv`).
That makes it drop straight into a left→right feed that splits into two
branches, such as the stator and rotor paths of a doubly-fed induction
generator.

<Snippet name="transformer3-example" />

Unlike the two-winding [`transformer`](/symbols/grid/transformer/), a
three-winding transformer has **three terminals**, so it cannot orient
itself along a single in→out line. It is therefore a **one-node symbol**:
place it at a point and rotate with `angle:`.

## Parameters

| Name                                                | Default                       | Description                                                                                                                                                  |
| --------------------------------------------------- | ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `radius`                                            | `0.32`                        | Radius of each circle.                                                                                                                                       |
| `distance`                                          | `0.42`                        | Centre-to-centre spacing of the equilateral circle cluster.                                                                                                  |
| `fill`                                              | `none`                        | Fill applied to all three circles.                                                                                                                           |
| `stroke`                                            | `0.8pt`                       | Stroke applied to all three circles.                                                                                                                         |
| `primary-stroke`                                    | `stroke`                      | Per-winding stroke for the HV (left) circle.                                                                                                                 |
| `secondary-stroke`                                  | `stroke`                      | Per-winding stroke for the LV (upper-right) circle.                                                                                                          |
| `tertiary-stroke`                                   | `stroke`                      | Per-winding stroke for the TV (lower-right) circle.                                                                                                          |
| `primary-fill` / `secondary-fill` / `tertiary-fill` | `fill`                        | Per-winding fills.                                                                                                                                           |
| `lead`                                              | `0`                           | Length of the lead stub from each circle edge to its terminal anchor (`0` = flush on the edge). See [Controlling the terminals](#controlling-the-terminals). |
| `hv-angle` / `lv-angle` / `tv-angle`                | `180deg` / `60deg` / `-60deg` | Direction each terminal exits its circle, CCW from +x.                                                                                                       |
| `vector`                                            | `none`                        | In-circle winding marks, three entries (hv, lv, tv) — see below.                                                                                             |
| `vector-size` / `vector-stroke`                     | `0.45` / `auto`               | Mark reach (fraction of the radius) and stroke (`auto` follows each winding's stroke).                                                                       |
| `label`                                             | `none`                        | Typical use: voltage ratings, e.g. `[23 / 0,96 / 0,69 kV]`.                                                                                                  |

## Vector-group marks

`vector:` draws the winding-connection glyphs _inside_ the circles —
three entries (hv, lv, tv), each `"delta"`, `"wye"`, `"zigzag"` or
`none`. The trefoil spacing automatically widens (when needed) so the
marks stay clear of the neighbouring outlines, and the marks stay
upright under `angle:`:

## Anchors

The three terminal anchors sit where each winding's wire exits its
circle — by default radial from the centroid, but you can re-aim and
extend them (see [Controlling the terminals](#controlling-the-terminals)).
Positions are given in the symbol's local frame, before rotation:

| Anchor                  | Winding                 |
| ----------------------- | ----------------------- |
| `hv` / `primary` / `in` | HV — left circle        |
| `lv` / `secondary`      | LV — upper-right circle |
| `tv` / `tertiary`       | TV — lower-right circle |

plus `center`, `north`, `south`, `east`, `west`. There is no single
`out` anchor (a three-winding transformer has two outgoing windings) —
wire `lv` and `tv` explicitly.

## Controlling the terminals

By default each terminal exits its circle **radially from the centroid**
— HV at `180deg` (left), LV at `60deg` (up-right), TV at `-60deg`
(down-right) — and sits flush on the circle edge. Two style keys move the
connection points:

- **`hv-angle` / `lv-angle` / `tv-angle`** set the _direction_ each
  winding's wire leaves its circle, measured counter-clockwise from the
  +x axis. Re-aim a secondary straight up (`90deg`) or down (`-90deg`),
  or point a terminal anywhere on its circle.
- **`lead`** sets the _distance_ the terminal sits beyond the circle
  edge, drawing a stub in that winding's stroke. `0` (default) keeps the
  anchor flush on the edge.

The two compose — the terminal anchor is computed as

```
circle-centre + (radius + lead) · (cos θ, sin θ)
```

where `θ` is that terminal's angle. The default angles happen to equal
the radial direction to each circle and `lead` is `0`, so the defaults
reproduce the flush, on-the-edge terminals — existing diagrams are
unchanged.

The `hv` / `lv` / `tv` anchors always track the resulting positions, so
wires and elbows attach correctly however you aim or extend the
terminals. Left to right below: the defaults, a `lead` stub on every
terminal, and the secondaries re-aimed vertically with leads:
