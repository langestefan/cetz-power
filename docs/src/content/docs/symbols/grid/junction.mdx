A small circle marking a connection point on a conductor — the node
notation of distribution-network overview diagrams. A **filled** circle
is a closed (connected) point; a **hollow** one (`open: true`) is an
open point — the _netopening_ that marks where a normally-open ring is
split.

<Snippet name="junction-example" />

## Open points mask the conductor

The open variant paints its interior (white by default), hiding the
line drawn beneath it — so the ring visually splits at the open point.
That only works if the junction is drawn **after** the wire it sits on;
make junctions the last symbols you place.

<Snippet name="junction-netopening" />

## Styling

`fill: auto` (the default) resolves to the stroke's paint when closed
and to white when open, so a red-stroked junction is a red dot. Pass an
explicit `fill:` to override either.

<Snippet name="junction-styling" />

## Parameters

| Name     | Default         | Description                                                         |
| -------- | --------------- | ------------------------------------------------------------------- |
| `radius` | `0.09`          | Circle radius.                                                      |
| `open`   | `false`         | `false` = filled dot (closed); `true` = hollow circle (open point). |
| `fill`   | `auto`          | Body paint. `auto` → stroke paint when closed, white when open.     |
| `stroke` | `0.8pt + black` | Circle outline.                                                     |
| `label`  | `none`          | Standard label dict (default `anchor: "north"`, `distance: 0.15`).  |

## Anchors

| Anchor                           | Position                                                                      |
| -------------------------------- | ----------------------------------------------------------------------------- |
| `in`, `out`, `center`            | The connection point itself.                                                  |
| `north`, `south`, `east`, `west` | On the circle — safe wire endpoints when you want a line to stop at the edge. |

switchgear marks.
