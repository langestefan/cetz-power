A small square (or rectangle) sitting inline on a wire. This is the
conventional SLD notation for a circuit breaker — it deliberately
looks different from the [switch](/symbols/protection/switch/) symbol
so the reader can tell at a glance which feeders have CBs and which
have plain disconnectors.

<Snippet name="breaker-example" />

## Between two buses

The two-node placement orients the box along the in→out line and
draws its own lead stubs to the bus mid-points:

<Snippet name="breaker-bus" />

`fill:` is a useful per-call override for colour-coding by voltage
level — pass `red.lighten(70%)` for HV, `blue.lighten(70%)` for MV,
etc. Then a glance at the diagram tells you the breaker's role.

## The × variant

`kind: "cross"` draws the compact **×** used in network-overview
diagrams (the Dutch distribution-planning convention for a switchgear /
breaker position). The wire runs straight through it — no gap, no box.
It also supports **one-node** placement: pass a single position (plus
an optional `angle:`) to drop the mark directly onto an existing run,
which is handy when peppering a long feeder with breaker positions:

<Snippet name="breaker-cross" />

See the [distribution-rings recipe](/recipes/distribution-rings/) for
it in context, together with [junction](/symbols/grid/junction/)
connection points.

## Parameters

| Name     | Default         | Description                                                                  |
| -------- | --------------- | ---------------------------------------------------------------------------- |
| `size`   | `0.3`           | Side length of the square box / span of the ×.                               |
| `kind`   | `"square"`      | `"square"` = the conventional SLD box; `"cross"` = an × on the wire.         |
| `stroke` | `0.8pt + black` | Stroke for the body outline and the lead stubs.                              |
| `fill`   | `none`          | Box fill (ignored for `"cross"`). Useful for colour-coding by voltage level. |
| `label`  | `none`          | Standard label dict (default `anchor: "north"`, `distance: 0.15`).           |

## Anchors

| Anchor                           | Position                                  |
| -------------------------------- | ----------------------------------------- |
| `in`, `out`                      | The two endpoints (passed by the caller). |
| `center`                         | Centre of the box.                        |
| `north`, `south`, `east`, `west` | The four sides of the box.                |
