An electric-vehicle charging station: a charging pedestal (column with
a lightning bolt, connector holster and base plinth), a side-view car,
or both — joined by the charging cable into a plug on the car's rear
panel — inside a **square** device box (the same enclosure look as
[factory](/symbols/loads/factory/) /
[plant](/symbols/generation/plant/)). `kind:` picks the composition:
`"ev-charger"` (car + pedestal + cable, the default), `"charger"`
(pedestal only) or `"ev"` (car only). The lead drops from the
connection point onto the box top; pass `elbow: <units>` to route it
as an L-shape.

Like [load](/symbols/loads/load/), the station accepts the
context-aware placement arguments `on: "<bus-name>"` (straight drop
below a horizontal bar, `side: "north"` to flip above; automatic
L-bend off a vertical bar, `side: "east"`/`"west"`) and
`towards: <coord>` — both replace `angle:`. See
[Automatic placement](/getting-started/auto-placement/).

## Styling

`fill:` tints the car body and pedestal, `box-fill:` the box interior;
`box: false` drops the enclosure and hangs the bare pictogram from the
pedestal top (or, car only, the roof centre). `height:` sizes the
pedestal and everything else scales with it.

## Parameters

| Name       | Default        | Description                                                                              |
| ---------- | -------------- | ---------------------------------------------------------------------------------------- |
| `kind`     | `"ev-charger"` | Composition: `"ev-charger"` (both + cable), `"charger"`, `"ev"`.                         |
| `height`   | `0.7`          | Pedestal height; the car and box scale with it.                                          |
| `lead`     | `0.15`         | Length of the stub wire from the connection point to the box (or symbol) top.            |
| `elbow`    | `0`            | If non-zero, route the lead as an L: across by this many units, then down to the symbol. |
| `on`       | `none`         | Bus name to orient the drop off — replaces `angle:` (`side:` picks the side).            |
| `towards`  | `none`         | Coordinate the symbol aims at — replaces `angle:`.                                       |
| `box`      | `true`         | Enclose the pictogram in a square device box.                                            |
| `box-fill` | `none`         | Box interior paint.                                                                      |
| `stroke`   | `0.8pt`        | Stroke override.                                                                         |
| `fill`     | `none`         | Car body and pedestal fill.                                                              |

## Anchors

`in` (= connection point), `north`, `south` (= bottom centre),
`east` / `west` (mid-height of the sides), `center`, `default`, plus
`charger` (pedestal top centre) and `ev` (car body centre) when the
respective part is drawn. The compass anchors sit on the box when it
is drawn, on the pictogram extents with `box: false`. With `lead: 0`
the box top sits on the position itself, so `west`/`east` are handy
for wiring the station inline at the end of a horizontal run.
