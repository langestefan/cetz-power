The standard control-notation multiplication point: a circle with an
inscribed `×` whose diagonals span the full circle. Used for
multiplication, modulation and mixing in converter control schemes —
see the [grid-side converter recipe](/recipes/gsc-control/) for it in
context:

<Snippet name="mixer-example" />

## Parameters

| Name     | Default         | Description                                                        |
| -------- | --------------- | ------------------------------------------------------------------ |
| `radius` | `0.16`          | Circle radius.                                                     |
| `stroke` | `0.8pt + black` | Circle and cross stroke.                                           |
| `fill`   | `none`          | Circle fill — `white` masks a conductor beneath.                   |
| `label`  | `none`          | Standard label dict (default `anchor: "north"`, `distance: 0.15`). |
| `angle`  | `0deg`          | Rotation.                                                          |

## Anchors

| Anchor                                                 | Position                          |
| ------------------------------------------------------ | --------------------------------- |
| `in`, `out`, `center`                                  | The centre.                       |
| `north`, `south`, `east`, `west`                       | Cardinal points on the circle.    |
| `north-west`, `north-east`, `south-west`, `south-east` | The 45° points on the circle.     |
